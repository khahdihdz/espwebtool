Nếu không tự vào chế độ nạp được (Auto Boot thất bại):

  1. Giữ nút BOOT
  2. Nhấn rồi thả nút RESET/EN

  4. Bấm lại "Kết nối ESP32"

Firmware

Mặc định chỉ cần 1 file firmware.bin ghi ở offset 0x10000. Bấm "Thêm file" nếu bạn cần nạp riêng bootloader.bin (0x1000) và partitions.bin (0x8000).
