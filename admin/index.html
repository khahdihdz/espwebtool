Quản lý Firmware & Manifest

Công cụ này chạy hoàn toàn trên trình duyệt (không có backend). Nó giúp bạn đóng gói firmware và sinh sẵn file manifest.json đúng chuẩn ESP Web Tools, cũng như quản lý danh sách phiên bản bằng localStorage. Sau khi tạo xong, bạn tải file về và commit thủ công vào thư mục /firmware/ của dự án rồi cập nhật boards.json.

Trang quản trị này không có máy chủ lưu trữ: mọi thay đổi chỉ tồn tại trong trình duyệt của bạn (localStorage) cho đến khi bạn tải file kết quả về và tự cập nhật vào mã nguồn dự án.
